# Reglas de Trabajo para el Proyecto (TecnoEduca)

## ⚠️ Control de Versiones y Git (REGLA FUNDAMENTAL)
- **NUNCA hacer commit ni push a GitHub** (ni ejecutar comandos que suban cambios a ramas remotas como `git push`, `git commit`, etc.).
- La usuaria (Rosana) revisa personalmente cada cambio y es quien se encarga de realizar los commits y pushes a GitHub a su propio ritmo.
- Todo el trabajo del asistente se realiza estrictamente en los archivos locales del workspace.
